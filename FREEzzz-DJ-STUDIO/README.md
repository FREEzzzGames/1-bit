# FREEzzz DJ STUDIO — MVP 0.1.0

Локальная web-студия для воспроизведения музыки и генеративной аудиореактивной графики.

## Реализовано
- Загрузка локальных аудиофайлов (MP3/WAV/OGG и форматы, поддерживаемые браузером).
- Локальная библиотека текущей сессии, плеер, перемотка и громкость.
- Оценка BPM эвристическим onset-envelope autocorrelation (ориентировочно, не профессиональный beatgrid).
- Спектральный анализ через Web Audio API.
- WebGL-визуализация Three.js: PARTICLES, FRACTAL-подобный режим, WAVE и TORUS-сцена.
- Адаптивный интерфейс.

## Пока не реализовано
AI DJ, stem separation, remix/mashup engine, реальные FX, запись аудио/видео и автоматическое сведение. Эти блоки показаны как roadmap.

## Требования
Node.js 20.19+ или 22.12+, npm.

## Запуск
```bash
npm install
npm run dev -- --host 0.0.0.0
```
Откройте адрес Vite на компьютере или в локальной сети.

Аудиофайлы обрабатываются в браузере и не загружаются на сервер. Для полностью автономного режима удалите импорт Google Fonts в `src/style.css`.
